# The Cost of Security: Quantifying the Security-Performance Tradeoff in Linux DPDK Environments
Source: https://github.com/DPDK/dpdk

This project uses the above open-source library for kernel-bypass. The code in src/ contains modified examples of the above repository in order to measure the security-performance tradeoff of Linux DPDK. For more details, please read `paper.pdf`.

To replicate results, please put the folders in `src/` into `https://github.com/DPDK/dpdk/tree/main/examples` and build DPDK from source.
